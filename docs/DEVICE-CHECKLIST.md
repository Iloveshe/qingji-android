# Redmi 实机检查

手机：Redmi Note 12 Turbo，用户报告 Android 16 / HyperOS 3、无 root。以下是需要执行的验证，不代表已经测试通过。

1. 安装后打开轻记，先不授权；应显示真实空账本，无伪造账单。独立演示应不写入账本。
2. 授予通知读取，勾选所用 App，确认显示服务已连接。实际支付 0.01 元或其他小额；有完整交易通知时应入账。
3. 开启交易短信，对照真实短信。消费金额应与余额区分；同笔银行短信与钱包通知在足够匹配时合并，没有商户时应待确认。
4. 同一商户连续支付两笔同金额，核对应保留两笔；不同钱包 / 不同订单号不可误合并。
5. 填写本人卡尾号，进行本人账户转移，再消费；账户移动不计入收入 / 支出，消费计一次。
6. 向他人转账，验证不会直接当作内部转账；需要核对付款性质。
7. 退款成功通知应生成退款记录，冲减净支出；退款申请 / 退款中不入账。
8. 分享有明确日期的支付截图，核对日期与去重；缺少日期的旧截图应待确认。
9. 开启截图目录扫描，新增支付截图；普通相册图片与开启前的截图不应批量入账。
10. 开启无障碍，仅选定 App 的交易页面产生候选；密码输入和聊天等无明确交易信息的界面不得自动入账。
11. 主动授权临时屏幕识别，检查常驻通知、停止按钮、旋转屏幕、系统撤销授权、锁屏停止。银行安全页面黑屏属于平台限制。
12. 暂停总开关，确认不会继续新入账；恢复后只处理新事件。
13. 一笔待确认交易分别测试：核对为支出、改成内部转账、与已有账单合并、忽略。同来源重复推送不得恢复已忽略记录。
14. CSV 导出到选定位置，核对分币、日期、状态及中文编码；导出不包含模型密钥和完整消息正文。
15. 默认关闭云端模型，断网使用通知 / 短信 / OCR。可选模型仅在显式配置后访问指定 HTTPS 接口。
16. 后台运行 30 分钟、2 小时；重启；清理最近任务；强制停止后重新打开，分别记录采集与电量表现。
17. 从已发布的 0.1.0 覆盖安装 0.1.1，不卸载，确认账本和采集设置保留；设置页应出现“应用更新”。
18. 更新设置：开关与测试版渠道保存，连续启动 12 小时内不重复检查，手动检查可重试；断网时显示失败，其他采集仍可用。
19. 使用同一签名更高 versionCode 的测试包验证下载、哈希与签名拒绝、安装未知应用授权返回、系统取消 / 确认安装及数据保留，详见 UPDATES.md。

20. 0.1.2 覆盖安装后重新切换无障碍开关，开启自动窗口 OCR。关闭云闪付交易通知，用正常付款或单笔详情检查是否采集；无日期应进待确认，旧账单保留历史日期。
21. 验证密码 / 编辑页面、锁屏、切换 App、取消勾选、暂停开关、安全页面不继续 OCR；快速动画不会使读取永远延后。
22. 悬浮窗授权、关闭、拖动、点按、锁屏隐藏；撤销“显示在其他应用上层”后不显示；悬浮窗不能干扰当前云闪付窗口识别。

每个异常请保留：系统版本、来源 App 包名、去敏文案、实际金额与时间、预期类型、轻记的判断，以及设置中的页面处理状态。不要提供验证码、完整卡号、密码或模型密钥。
