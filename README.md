# 轻记 · Android 自动记账

为 **Redmi Note 12 Turbo / Android 16 / HyperOS 3 / 无 root** 场景编写的原生 Android 项目。默认本地处理，无登录、无服务器。最低 API 26，编译及目标 API 36。

**当前版本 0.1.3：63 项记账测试、31 项更新策略测试、18 项采集策略测试、22 项页面记忆与手动识别测试，另有 33 项 OCR 可靠性、诊断白名单和证据加密测试，共 167 项通过；SQLite 升级保留检查通过。** Android 编译、lint 及 APK 验证见 [验证记录](docs/VALIDATION.md)。尚未在你的 Redmi 手机上实机验证，不能保证所有银行格式或后台场景都已覆盖。

源码仓库：https://github.com/Iloveshe/qingji-android

安装包发布页：https://github.com/Iloveshe/qingji-android/releases/tag/v0.1.3

## 0.1.3 识别可靠性与证据修复

- OCR 候选统一先进入待确认，核对截图后才计入收支；不再拼接无障碍和 OCR 两份文字。自动页面需要单笔付款凭证特征，裸数字、卡尾号、时间及聊天中的价格不能直接作为金额。无法根据目前反馈还原“5999”的具体原图，因此不声称实机问题已完全复现。
- 可开启本机加密截图证据，交易详情支持缩放查看实际 OCR 输入图；文字来源、未开启保存或旧版历史记录会显示缺图原因。旧图无法补回。
- 新增默认关闭的 HTTPS 远程脱敏诊断配置，以及无需服务器的预览、JSON 导出。没有内置接收服务；未配置、未主动开启时不会发送。详见 [诊断与截图说明](docs/DIAGNOSTICS.md)。
- 数据库平滑迁移到版本 2，保留原账本；旧版未经人工核对、且只有 OCR 证据的自动确认记录退回待确认，避免错误收支继续计入。

## 同版 MVP 改进

- **悬浮快捷识别**：开启“悬浮识别与页面记忆”后，点按左侧识别当前已勾选 App 的窗口；长按左侧尝试记住付款页面；拖动左侧移动悬浮窗，右侧“账本”打开轻记。手动识别也遵守解锁、来源选择、输入页面排除和 OCR 同意开关，截图重试间隔至少 4 秒。
- **本地页面记忆**：保存应用包名、页面组件和“结构 + 固定付款标签”的哈希，不保存金额、商户、截图或正文。对记住的付款页面自动补充 OCR。最多 24 个，设置可逐个删除或清空；无稳定组件或付款特征的页面拒绝记忆。页面结构变化后需要重新记忆，不能保证任意页面都能学习。
- **采集诊断**：“设置 → 数据与诊断 → 查看采集诊断”展示权限 / 服务 / 窗口截图能力和最近 32 条处理结果，包括已入账、已合并、待确认、重复跳过及未匹配原因。可复制或清空，不包含交易正文、金额、商户或卡号。
- **账户冲突保护**：相似账单或相同订单的已知支付卡尾号冲突时，停止自动合并并进入待确认。本人转账与同金额消费继续分别处理，转账不计支出。

参考 AutoAccounting 的页面记忆和采集分层概念后独立实现，具体来源及差异见 [docs/REFERENCES.md](docs/REFERENCES.md)。未引入上游 SDK 或复制上游实现。证据功能增加数据库迁移，保留已有账单。

## 没有云闪付通知也能识别

0.1.2 增加 **支付窗口自动 OCR（无通知）**。在“设置 → 自动采集来源”开启，授予无障碍权限，并在“识别哪些 App”勾选云闪付。升级后建议将系统无障碍里的轻记关闭再开启，以加载新增截图能力。此功能默认关闭，不依赖云闪付发通知，也不需要每次授权录屏。

正常付款或进入单笔付款详情时，先读取页面文字；无法识别时，在 Android 14+ 对当前选定云闪付窗口自动截图并使用打包的中文模型识别。其他选定 App 只有出现支付结果或交易详情提示时才补充 OCR，不对普通微信聊天窗口自动截图。未开启截图证据时图片只在内存处理；开启后匹配交易的 OCR 输入图加密保存在本机，不随诊断上传。

另增悬浮提示，对应系统“显示在其他应用上层”权限。0.1.3 中入口升级为 **悬浮识别与页面记忆**，依赖已开启的页面无障碍服务，锁屏隐藏，不展示金额或账单正文。悬浮窗权限本身不读取账单，自动 OCR 与悬浮窗可以分别开关。设置显示最近页面处理状态，便于定位权限、窗口读取、OCR 和识别格式问题。

页面未显示、没有通知或短信时，不能直接查询云闪付后台交易；禁止截图的安全页面仍可能不可识别。没有明确日期、方向或单笔金额时保留为待确认，不能把历史账单直接当作刚发生的消费。完整边界见 [docs/CAPTURE-MODES.md](docs/CAPTURE-MODES.md)。

## 应用更新

0.1.1 增加 **设置 → 应用更新**：当前版本、启动时自动检查、接收测试版、立即检查、下载进度、安装已下载的更新和 GitHub 发布页入口。启动检查默认开启，每 12 小时最多一次；失败时可以随时手动重试。接收测试版默认开启，因为当前 0.1.x 使用 GitHub 预发布渠道。

检查只读取本仓库的公开 Release 信息，不发送账单、短信、截图或模型密钥。检查使用版本列表而非 `/releases/latest`，可发现预发布版本，并按整数 versionCode 选择兼容系统的新版。关闭“启动时自动检查”后仍能手动检查。

下载由你确认后开始，可能使用移动流量，下载期间请保持应用打开。安装包在应用私有缓存中保存，检查文件大小、SHA-256、包名、版本、最低 Android 版本及与已安装 App 相同的签名。系统“允许安装未知应用”授权后，会再次校验安装包并打开安装确认，不能静默安装。中断或失败后可重试，也可从 GitHub 发布页手动下载。

**0.1.0 没有更新入口，需要先手动覆盖安装当前版本；不要卸载旧版。** 已发布的 0.1.x 使用同一调试签名，覆盖安装保留本地数据。自行编译或 GitHub Actions 备用构建的随机调试签名通常与发布版不同，不能作为发布版升级包。

维护者发布后续版本的要求见 [docs/UPDATES.md](docs/UPDATES.md)。

## 第一版实现了什么

| 来源 / 功能 | 实现方式 | 使用条件与边界 |
| --- | --- | --- |
| 微信、支付宝、云闪付、银行通知 | `NotificationListenerService` | 授予通知读取；通知自身必须包含金额或其他可用交易字段。分组摘要不入账。 |
| 新到达的交易短信 | `RECEIVE_SMS` 广播，拼接分段短信 | 开启短信采集并授予权限；默认仅允许 955、953、106 前缀，可自行修改；不读取历史短信，忽略验证码。 |
| 可见支付页面 | 无障碍读取文本 | 开启开关并授予权限；只读取勾选 App，跳过密码和可编辑节点，不点击、不操作支付。只能在页面显示时获取。 |
| 支付窗口自动 OCR | Android 14+ 无障碍窗口截图、本地中文 OCR | 单独同意并开启；云闪付及其他选定 App 的交易结果窗口可补识别。无通知也可工作，安全页面可能受限。 |
| 悬浮采集状态 | `SYSTEM_ALERT_WINDOW`、页面无障碍服务 | 单独开启并授权“显示在其他应用上层”；可拖动、锁屏隐藏，不读取或展示账单。 |
| 截图分享 / 单张导入 | Android 分享入口、文件选择器、打包的中文 ML Kit OCR | 本地识别，OCR 先进入待确认；可选加密保存本次 OCR 输入图。 |
| 新截图自动识别 | 系统 `JobScheduler` 相册内容触发 | 可选图片权限；只查询开启后新增的截屏目录，不扫描普通照片。系统可能延迟任务。 |
| 临时屏幕识别 | `MediaProjection` 前台服务 + OCR | 每次由用户授权；需要无障碍判断前台支付 App；每 4 秒最多一帧、常驻通知、锁屏停止。银行安全页面可能是黑屏。 |
| 本地自动入账 | 金额、交易方向、日期、商户与类型规则 | 当前识别算法为**本地规则及 OCR**，未集成本地大语言模型。明确通知 / 短信可自动入账，OCR 候选先待确认。 |
| 可选云端模型 | HTTPS Chat Completions 分类接口 | 默认关闭；填写接口、模型、API Key 后，只为新待确认交易建议分类。不会修改金额、日期或自动确认交易。 |
| 账单与核对 | 总览、账单筛选、待确认、证据查看、编辑、忽略、人工合并 | 转账不计收支；退款冲减支出；已忽略交易不会被同一事件恢复。 |
| 数据导出 | Android 保存文件选择器，UTF-8 CSV | 导出含已确认、待确认和已忽略状态；无截图、短信全文和模型密钥。导出文件由你选择保存位置。 |

系统通知仅从勾选的金融 App 获取；不会记录整个系统通知流。未发通知且没有可读页面或短信的交易、隐藏金额、无法读取的安全页面或未知交易格式都可能漏记。现有系统录屏文件 / 视频导入暂不支持；支持的是当前可见窗口及授权期间的实时画面 OCR。

## 转账与去重

你举的“先转到云闪付的一张本人银行卡，再消费”会保留资金移动和实际消费两条记录：

```
转入本人银行卡 500 元 → 内部转账 → 不计入收入 / 支出
咖啡消费 38 元        → 支出     → 支出 +38 元
银行短信消费 38 元    → 同笔消费的证据 → 不重复增加支出
```

不是将 500 元与 38 元强行合并。转账需要有本人账户、充值 / 提现 / 信用卡还款等明确含义，或能匹配你填写的两个本人账户尾号。普通“转账成功”不自动断定为本人账户互转，而是待确认。

- 同一来源事件重复投递直接忽略；指纹只保存哈希。
- 同一订单、类型、金额和币种可合并；同一订单金额冲突进入待确认。
- 已知支付账户尾号冲突时，不会自动吞并相似账单；同一订单的账户冲突也进入待确认。
- 订单号按来源 / 订单字段分范围，商户订单号不能跨不同商户复用。
- 不同来源在短时间内商户与金额一致可合并；没有明确日期的可视页面只能凭订单号强匹配。
- **仅凭金额相同不会自动合并。** 商户缺失时可能重复的记录进入待确认，暂不计入统计。
- 同一来源两个独立消费、不同订单、不同商户、不同钱包的独立消费都保留。
- 退款独立记录，冲减净支出，不与原支付互相吞掉。
- 余额不作为交易金额，历史截图使用其交易日期，人民币统计不混入外币。
- 跨来源的商户与时间匹配是启发式规则，仍可能误判。可在账单详情查看依据；建议先用小额真实交易核对。

## 编译与安装

### Android Studio（建议）

1. 安装支持 Android Gradle Plugin 8.11.1 的 Android Studio，使用 JDK 17 或 21。
2. 在 SDK Manager 安装 Android SDK Platform **36** 和 Android SDK Build-Tools **35.0.0**。
3. 打开本项目。首次同步需要访问 Google Maven、Maven Central 和 Gradle 下载站。
4. 本项目提供下载校验版 `gradlew` shell 引导脚本，**尚未附标准 Gradle wrapper JAR**。Android Studio 如提示 wrapper 不完整，可以选择已安装的 Gradle **8.13**，或在终端先运行 `./gradlew wrapper --gradle-version 8.13` 生成标准 wrapper。
5. 构建 Debug APK：`./gradlew :app:assembleDebug`（macOS / Linux），或使用下方 Windows 脚本。
6. 安装 `app/build/outputs/apk/debug/app-debug.apk`。这是调试包，适合你本人试用。公开分发前需使用你自己的长期签名密钥。

`local.properties` 示例（不要提交本机路径）：

```properties
sdk.dir=/你的/Android/Sdk
```

命令行：

```bash
chmod +x gradlew scripts/*.sh
./gradlew :app:assembleDebug :app:lintDebug
# 可选，USB 调试连接手机后
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Windows PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-windows.ps1
```

本地规则测试无须 Android SDK：

```bash
bash scripts/test-core.sh
bash scripts/check-source.sh
```

## 在 Redmi 上开启

打开轻记 → 设置，按需要逐项开启：

1. **通知读取**：基础来源，建议最先开启。
2. **交易短信**：允许接收新短信。侧载 App 可能遇到系统权限限制，无须将轻记设为默认短信应用。
3. **支付页面识别**：系统无障碍权限；侧载 APK 如出现“受限设置”，到应用信息中允许受限设置后再尝试。
4. **本人银行卡尾号**：只填你自己的卡尾号；多个尾号用逗号分隔。完整卡号不需要填。
5. **勾选实际使用的 App**。预设部分银行包名，不保证适配全部银行版本，支持补充包名。
6. **后台**：应用信息 → 电量与性能 → 无限制；开启后台自启动；最近任务中锁定轻记。不同 HyperOS 构建的菜单名称可能有差异。
7. 截图目录扫描与临时屏幕识别按需要开启。屏幕授权不能永久保持，录屏也不会在开机后自行重启。

“强制停止”会阻止后台接收，需要重新打开轻记。通知页面的“服务已连接”会在系统完成绑定后显示；可以点击“重新连接通知采集”。系统升级、重启、后台限制可能需要复查权限。

## 隐私

- 交易数据库在应用私有目录，依赖 Android 文件加密与应用沙箱，**没有额外的 SQLCipher 数据库加密**。
- 禁用应用系统备份。OTP、密码框、非交易消息不入库；不保存完整短信 / 页面文本，只保存提取的金额、商户、类型、时间、账户尾号和判断摘要，以及事件哈希。
- 截图、屏幕图像只在内存处理，不生成录屏文件。
- 云端分类默认关闭，开启后仅向你填写的 HTTPS 接口发送金额、币种、商户、类型、本地分类。模型 API Key 使用 Android Keystore 的 AES-GCM 加密保存，不写日志、不包含在导出中。
- 默认功能不调用云端模型。本项目包含第三方本地 OCR SDK，其初始化行为依赖 SDK；这是“交易识别在本地”，不是经过网络抓包验证的“绝对零网络请求”。
- 自动版本检查默认开启，仅请求 GitHub 公开版本信息，可在“应用更新”关闭；下载更新需另外确认。
- 可导出 CSV、清空本地账单、清除模型密钥、撤销系统权限或卸载。
